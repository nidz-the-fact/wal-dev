# Preview data from Walrus using blob ID

###

## Command <Badge type="info" text="wal read" />
```bash [npm]
wal read <blobID>
```
- A unique ID for data (file or text) uploaded to Walrus Protocol

###

## Usage 
::: code-group
```bash [bash 1]
wal read blobIDxabc --network testnet
```
```bash [bash 2]
wal read blobIDxabc -n testnet
```
::: 

###

## Option
> 🔴 Required, 🟡 Optional

- 🔴 `-n, --network` `<network>`: Specify network mainnet or testnet
